# Document browser UI

## Overview

`app.js` connects the editor to the local Gleam document API and Phoenix.
`collab_docs_client.mjs` is generated by the bundling script; its implementation
belongs to the [client source](../../client/src/README.md), not a second
hand-maintained module.

## Interface

- `app.js` imports the generated client bundle and starts on page load;
  it exports no module API.
- The UI reads tenant/document context from page metadata and the URL.

## Invariants

- `app.js` requires the `#blocks`, `#add-todo`, and `#add-note` page elements
  before startup.
- The textarea event handlers debounce state pushes by 400 ms (`app.js`).

## Side effects

- `app.js` joins a Phoenix channel with a tenant token, renders and edits the
  DOM, and sends document state updates.
- `scripts/bundle-client.mjs` in the example root writes the generated bundle.

## Verification

From the repository root: `pnpm -C examples/collab_docs build:client`, then
`pnpm -C examples/collab_docs test` for Playwright verification.
