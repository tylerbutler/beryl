# beryl_channels

Composable channel layer for [beryl](https://hex.pm/packages/beryl)
real-time sockets.

> [!IMPORTANT]
> beryl is not yet 1.0. The API is unstable, features may be removed in minor
> releases, and quality should not be considered production-ready.

This package is currently an ADR 0003 release scaffold only. It exists as an
independently publishable workspace package and will gain the public
channel-composition API in follow-up tasks.
