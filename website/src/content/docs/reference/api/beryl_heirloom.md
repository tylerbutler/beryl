### `give_away`

```gleam
pub fn give_away(
  Table(a, b),
  to: process.Pid,
  data: c
) -> Result(Nil, OwnershipError)
```

Give the table to another live local process.

 The caller must own the table. The recipient observes completion through
 an `ETS-TRANSFER` message. The configured heir is unchanged.
